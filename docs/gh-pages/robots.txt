# NeverDry is a free, open-source project that WANTS discovery and citation,
# so search crawlers AND AI/GEO crawlers are allowed on purpose.
#
# Where this file counts: crawlers read robots.txt only at the root of a host,
# https://never-dry.github.io/robots.txt. This copy is served one level down,
# under /NeverDry/, so it is a statement of the policy rather than its
# enforcement. Nothing is lost while the host root answers 404, which crawlers
# read as "everything allowed"; the cost is the Sitemap line below, which they
# never see. The sitemap is therefore submitted by hand in Google Search Console
# and Bing Webmaster Tools. Serving this file at the host root would take a
# never-dry/never-dry.github.io repository.
